# Estatística Quiz

## Question 1
Um analista observa que a média aritmética de 12 processos investigativos é 24. Se um processo que durou 30 dias é substituído por um novo que durou apenas 18 dias, qual será a nova média aritmética do conjunto?

- [x] 23
- [ ] 22
- [ ] 23,5
- [ ] 25

**Hint:** Em vez de recalcular tudo, foque na variação da soma total dividida pelo número de elementos.

## Question 2
Considere uma distribuição de frequências acumuladas (ogiva) onde 30\% das observações estão abaixo de 10 unidades e 70\% estão abaixo de 20 unidades. Utilizando a interpolação linear, qual é o valor da mediana desta distribuição?

- [x] 15
- [ ] 14
- [ ] 12,5
- [ ] 17,5

**Hint:** A mediana corresponde ao ponto onde a frequência relativa acumulada atinge 50\%.

## Question 3
Seja $X$ uma variável aleatória com média $\mu = 10$ e desvio-padrão $\sigma = 4$. Se definirmos uma nova variável $Y = 30 - 2X$, quais serão a nova média e o novo desvio-padrão de $Y$, respectivamente?

- [x] 10 e 8
- [ ] 10 e -8
- [ ] 30 e 8
- [ ] 10 e 4

**Hint:** Lembre-se que constantes somadas não afetam a dispersão, mas multiplicadores afetam tanto a posição quanto a dispersão.

## Question 4
Sobre as propriedades das medidas de dispersão, assinale a afirmativa correta:

- [x] O coeficiente de variação é uma medida adimensional e permanece invariante sob mudanças de escala.
- [ ] O desvio-padrão é adimensional, facilitando a comparação entre diferentes unidades de medida.
- [ ] A variância é sempre maior ou igual ao desvio-padrão para qualquer conjunto de dados.
- [ ] Somar uma constante a todos os elementos de uma lista aumenta o desvio-padrão na mesma proporção.

**Hint:** Considere qual medida é usada especificamente para comparar a variabilidade de grupos com médias e unidades diferentes.

## Question 5
Em uma investigação policial, dois eventos $A$ e $B$ são considerados mutuamente exclusivos e possuem probabilidades positivas ($P(A) > 0$ e $P(B) > 0$). Qual afirmação sobre esses eventos é necessariamente verdadeira?

- [x] Os eventos são dependentes.
- [ ] Os eventos são independentes.
- [ ] A probabilidade da união $P(A \cup B)$ é igual a 1.
- [ ] A interseção $P(A \cap B)$ é igual ao produto das probabilidades individuais.

**Hint:** Pense no que acontece com a chance de $B$ ocorrer se você já souber que $A$ ocorreu e eles não podem coexistir.

## Question 6
Uma urna contém 10 cartões numerados de 1 a 10. Se 3 cartões forem retirados simultaneamente, qual é a probabilidade de que 'pelo menos um' deles tenha um número par?

- [x] $\frac{11}{12}$
- [ ] $\frac{1}{12}$
- [ ] $\frac{1}{2}$
- [ ] $\frac{7}{12}$

**Hint:** A forma mais rápida de resolver problemas de 'pelo menos um' é calcular a probabilidade de 'nenhum' e subtrair de 1.

## Question 7
Ao analisar a assimetria de uma distribuição de salários em uma delegacia, observa-se que a média é superior à mediana. O que se pode concluir corretamente sobre a massa de dados?

- [x] A maioria dos funcionários ganha menos do que a média salarial.
- [ ] A maioria dos funcionários ganha mais do que a média salarial.
- [ ] A distribuição é perfeitamente simétrica.
- [ ] Existem exatamente a mesma quantidade de valores acima e abaixo da média.

**Hint:** Lembre-se do mnemônico: a média é 'puxada' pelos valores extremos (cauda), correndo atrás deles.

## Question 8
Um pesquisador deseja realizar uma amostragem em uma cidade. Ele decide dividir a população em bairros e sortear alguns bairros inteiros para entrevistar todos os moradores deles. Esta técnica é classificada como:

- [x] Amostragem por Conglomerado
- [ ] Amostragem Estratificada
- [ ] Amostragem Aleatória Simples
- [ ] Amostragem Sistemática

**Hint:** Observe se o sorteio recai sobre indivíduos específicos de cada grupo ou se o grupo inteiro é a unidade sorteada.

## Question 9
Qual das seguintes afirmações sobre o desvio-padrão é verdadeira?

- [x] Incluir um novo valor exatamente igual à média do conjunto reduz o desvio-padrão.
- [ ] O desvio-padrão de uma lista de valores constantes é igual a 1.
- [ ] O desvio-padrão pode assumir valores negativos se a média for negativa.
- [ ] O desvio-padrão é a média aritmética simples dos desvios de cada valor em relação à média.

**Hint:** Considere como a dispersão média é afetada quando você adiciona um dado que não se afasta nem um pouco do centro.

## Question 10
A moda é a única medida de tendência central que pode ser utilizada para qual tipo de variável?

- [x] Qualitativa Nominal
- [ ] Quantitativa Contínua
- [ ] Qualitativa Ordinal
- [ ] Quantitativa Discreta

**Hint:** Pense em uma variável onde você não consegue somar os valores nem colocá-los em uma ordem hierárquica.

## Question 11
Em uma caixa há 3 bolas brancas, 3 amarelas e 3 vermelhas. Se retirarmos duas bolas sem reposição, qual a probabilidade de que elas tenham cores diferentes?

- [x] $\frac{3}{4}$
- [ ] $\frac{1}{4}$
- [ ] $\frac{2}{3}$
- [ ] $\frac{1}{3}$

**Hint:** Calcular a probabilidade de serem da 'mesma cor' e usar o complementar costuma ser mais simples.

## Question 12
O gráfico Boxplot é uma ferramenta poderosa para análise exploratória. No entanto, ele falha em representar diretamente qual das seguintes medidas?

- [x] Média aritmética
- [ ] Mediana
- [ ] Amplitude interquartílica
- [ ] Outliers (valores discrepantes)

**Hint:** Diferencie medidas de posição baseadas em ordenamento (quantis) daquelas baseadas em soma de valores.

## Question 13
A variância de um conjunto de dados é calculada como 16 $kg^2$. Se cada valor do conjunto for multiplicado por 2, qual será a nova variância?

- [x] 64 $kg^2$
- [ ] 32 $kg^2$
- [ ] 16 $kg^2$
- [ ] 8 $kg^2$

**Hint:** Lembre-se que a variância está em unidades ao quadrado e responde ao quadrado das mudanças de escala.

## Question 14
Sobre o Teorema de Bayes, quando ele é mais comumente aplicado em questões de concursos?

- [x] Quando se deseja calcular a probabilidade de uma causa, sabendo que o efeito já ocorreu.
- [ ] Quando se deseja somar as probabilidades de dois eventos mutuamente exclusivos.
- [ ] Sempre que os eventos forem independentes e retirados com reposição.
- [ ] Para determinar se uma variável é discreta ou contínua.

**Hint:** Pense no enunciado que pede: 'sabendo que o resultado foi X, qual a chance de ter vindo da origem Y?'

## Question 15
Considere dois grupos: Grupo A com 20 pessoas e média 80; Grupo B com 30 pessoas e média 70. Qual é a média combinada (média das médias) dos dois grupos?

- [x] 74
- [ ] 75
- [ ] 72
- [ ] 76

**Hint:** A média combinada deve levar em conta o número de elementos de cada grupo como pesos.

## Question 16

- [ ] Ele substitui o Boxplot na identificação de outliers.

**Hint:** Pense em qual gráfico permite reconstruir a lista de dados brutos apenas olhando para ele.

## Question 17
Se o desvio-padrão de um conjunto de dados é zero, o que podemos afirmar categoricamente sobre esse conjunto?

- [x] Todos os valores do conjunto são iguais entre si.

## Question 18

- [x] A variância amostral utiliza $(n - 1)$ no denominador para evitar o viés de subestimação.

- [ ] A variância amostral é a raiz quadrada da populacional.
- [ ] O cálculo da variância populacional ignora a média aritmética.

**Hint:** Foque no divisor da fórmula que é ajustado quando trabalhamos apenas com uma parte da população.

## Question 19

## Question 20
