# Lógica Quiz

## Question 1
Em uma pesquisa com $200$ candidatos, constatou-se que $120$ estudam Português e $90$ estudam Matemática. Sabendo que $40$ candidatos estudam ambas as matérias, quantos candidatos não estudam nenhuma dessas duas disciplinas?

- [x] $30$
- [ ] $70$
- [ ] $40$
- [ ] $10$

**Hint:** Lembre-se de que a soma dos elementos de cada conjunto menos a interseção resulta na união dos conjuntos.

## Question 2
Um grupo de $100$ servidores foi consultado sobre o uso de dois sistemas, $S_1$ e $S_2$. Sabe-se que $65$ usam o sistema $S_1$ e $45$ usam o sistema $S_2$. Se todos os servidores utilizam pelo menos um dos sistemas, qual o número de servidores que utilizam apenas o sistema $S_2$?

- [x] $35$
- [ ] $10$
- [ ] $45$
- [ ] $55$

**Hint:** Diferencie o conjunto total de um item do grupo que utiliza 'apenas' aquele item.

## Question 3
De acordo com os conceitos de Diagramas de Venn, se $70\%$ dos funcionários de uma repartição possuem carro e $50\%$ possuem moto, e sabendo que todos possuem pelo menos um desses veículos, qual a porcentagem de funcionários que possuem ambos?

- [x] $20\%$
- [ ] $30\%$
- [ ] $50\%$
- [ ] $10\%$

**Hint:** O valor que ultrapassa o total de $100\%$ indica a região de interseção.

## Question 6
Considere a proposição composta: 'Jorge foi ao cinema e voltou desapontado'. Qual é a negação correta dessa afirmação segundo as leis da lógica?

- [x] Jorge não foi ao cinema ou não voltou desapontado
- [ ] Jorge não foi ao cinema e não voltou desapontado
- [ ] Se Jorge não foi ao cinema, então não voltou desapontado
- [ ] Jorge foi ao cinema, mas não voltou desapontado

**Hint:** Utilize a regra do 'Nenê' (nega, nega e troca o conectivo).
